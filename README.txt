KAVERI STAYS - API ASSIGNMENT
=============================

Two documents. Read them in the order they are numbered.

  1_Bridge_Notes.pdf    Eleven things your Python fortnight did not cover
                        that this assignment needs. Exercises, one per item.
                        Six pages. Do these first.

  2_API_Assignment.pdf  Nine stages, 100 marks. Ten pages.


BEFORE YOU START
----------------

1. Bring your own 05_schema_final.sql, 06_migration.sql and 07_seed.sql from
   the database assignment. This is not a fresh start. It is your own database
   with a door put on it.

2. Your Stage 5 validator from the database assignment must pass clean. If it
   does not, fix that before you write a single route. Everything in the API
   assignment assumes your constraints actually work.

3. Read all nine stages before you write any code. Same reason as last time.

4. Do the bridge exercises, then check yourself against the readiness table on
   the last page of 1_Bridge_Notes.pdf. Do not start Stage 1 with rows unticked.

5. Write def, not async def. The reason is in the first box of the bridge notes.


THE ONE RULE THAT RUNS ON TRUST
-------------------------------

Stage 3 is a specification, not an implementation. You commit it and send it in
BEFORE you are given openapi_reveal.yaml. If you edit it afterwards, the
Interlude is worth nothing to you, and the timestamps will say so.

You will receive openapi_reveal.yaml once your Stage 3 work has been submitted.
